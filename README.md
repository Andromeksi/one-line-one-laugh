A program that writes one funny line of text — an agent asked for one joke, no essays, and sent back 660 reasons why "the" is funny plus a 0.001 USDC invoice — to /output/entry.txt.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
